# Installation / 安装说明

## English

1. Download the latest DMG from [GitHub Releases](https://github.com/hyvasslli/MenuTrim/releases/latest).
2. Open it and drag MenuTrim to Applications.
3. Launch MenuTrim and grant the requested Device Control and Data Access permission.
4. If macOS blocks the current package, open **System Settings → Privacy & Security** and choose **Open Anyway**. Do not disable Gatekeeper.

The current package is Developer ID signed but has not yet completed Apple notarization.

## 中文

1. 从 [GitHub Releases](https://github.com/hyvasslli/MenuTrim/releases/latest) 下载最新版 DMG。
2. 打开安装包，将 MenuTrim 拖入“应用程序”文件夹。
3. 启动 MenuTrim，并授予“设备控制与数据访问”权限。
4. 如果 macOS 阻止当前安装包，请打开 **系统设置 → 隐私与安全性**，选择 **仍要打开**。不要关闭 Gatekeeper。

当前安装包已使用 Developer ID 签名，但尚未完成 Apple 公证。
