# Changelog / 更新记录

## 1.0.0 — 2026-09-22

- First stable MenuTrim release.
- Settings now show Version 1.0.0, author Yang Han (Hany), and the copyright notice.
- App and DMG are signed with Developer ID and distributed in an Apple-notarized, stapled DMG.
- MenuTrim 首个稳定版本。
- 设置窗口现显示 Version 1.0.0、作者 Yang Han (Hany) 及版权信息。
- 应用与 DMG 均已使用 Developer ID 签名，DMG 已通过 Apple 公证并写入公证票据。

## 0.3.1 — 2026-09-21

- Added a native macOS 27 Icon Composer app icon.
- Distributed as a Developer ID signed app in an Apple notarized and stapled DMG.
- Kept application behavior unchanged.
- 新增 macOS 27 原生 Icon Composer 应用图标。
- 应用使用 Developer ID 签名，DMG 已通过 Apple 公证并写入公证票据。
- 应用功能保持不变。

## 0.3.0 — 2026-09-21

- Initial public freeware release.
- Added one-click collapse and expand, auto collapse, keyboard shortcut, launch at login, multiple-display state handling, and spacing controls for compatible third-party items.
- 首个公开免费版本。
- 支持一键收起与展开、自动收起、键盘快捷键、登录启动、多显示器状态保持，以及兼容第三方图标的间距设置。
